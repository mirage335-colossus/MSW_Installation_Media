WHAT THIS PACKAGE DOES

  This package installs the software (Intel Rapid Storage Technology Driver) to
  enable the following device.

  Device name                               Device name in the Device Manager
  ----------------------------------        -----------------------------------
  Standard SATA AHCI Controller             Intel(R) 300 Sereies Chipset Family
                                            SATA AHCI Controller

  Refer to marketing materials to find out what computer models support which
  devices.

  If this package has been installed, updating (overwrite-installing) this
  package will fix problems, add new functions, or expand functions as noted
  below.

  This program is language independent and can be used with any language system.

DETERMINING WHICH VERSION IS INSTALLED


  [Mouse and Keyboard]
  1. Hold down the Windows logo key and press X to open a menu at the lower-left
     area of the screen.
  2. Select Device Manager from the menu.
  3. Double-click the IDE ATA/ATAPI controllers or Storage controllers category.
  4. Double-click either of the following devices;
       Intel(R) 100 Series/C230 Chipset Family SATA AHCI Controller
       Intel(R) 8th Generation Core Processor Family Platform I/O SATA AHCI Controller
  5. Select the Driver tab.
  6. Check Driver Version.

  [Touch]
  1. Press and hold the Start Button in the lower-left corner of the screen to
     open a menu.
  2. Select Device Manager from the menu.
  3. Double-tap the IDE ATA/ATAPI controllers or Storage controllers category.
  4. Double-tap either of the following devices;
       Intel(R) 100 Series/C230 Chipset Family SATA AHCI Controller
       Intel(R) 8th Generation Core Processor Family Platform I/O SATA AHCI Controller
  5. Select the Driver tab.
  6. Check Driver Version.

INSTALLATION INSTRUCTIONS

Note:
- If your computer runs satisfactorily now, it may not be necessary to update
  the software. To determine if you should update the software, refer to the
  Version Information section.


Manual Install

  This section assumes to use Internet Explorer and Windows Explorer.

  Downloading file
  1. Select the underlined file name. Once this is done, some pop-up windows
     will appear.
  2. Follow the instructions on the screen.
  3. In the window to choose Run or Save, select Save.
  4. The download will begin and complete.
     Once the download has completed, there may or may not be a message stating
     that the download completed successfully.

  Extracting files
  5. Make sure to be logged on with an administrator account.
  6. Locate the folder where the file was downloaded.
  7. Locate the file that was downloaded and double-click/double-tap it.
  8. Follow the instructions on the screen.
  9. In Extract or Install? window, select "Install", click Next, and move to
     step 13 to continue installation.
     Or, select "Extract only" and click Next to extract and keep the files
     on the specified folder.
 10. In the Select Destination Location window, click Extract.
     If you would like to select a different folder, click Browse.
 11. In the Ready to Install window, click Install. All the necessary files
     will be extracted to the folder selected in the step 10.
 12. Click Finish.

  Installing files
 13. In the Ready to Install window, click Install. All the necessary files will
     be extracted to the temporally folder. And extracted files will be deleted
     after installation.
 14. Click Finish.
 15. Follow the instructions on the screen to complete installation and restart
     the computer.
     IMPORTANT: Make sure to restart the computer after installation.


Unattended Install

  This is for system administrator's use only.

  1. Refer to the Manual Install section, and download and extract the file.

  2. At the command line, execute Install.bat with -s option.
     Example:
     [Path where the files were extracted]\Install.bat -s


*IMPORTANT: Make sure to restart the system after installation.

MS Inbox Driver Installation Method
 1. Open device manager.
 2. Open property of IDE ATA/ATAPI controllers.
    -or-
    Open property of Intel NVMe controller on Storage controller tree.
 3. Select "Driver" tab.
 4. Click button of update driver. then open window for update drivers guidance.
 5. Select "Brows my computer for driver software"
 6. Select "Let me pick from a list of available drivers on my computer"
 7. Select "Standard SATA AHCI controller", then click "Apply/OK" button.
    -or-
    Select "Standard NVM Express controller", then click "Apply/OK" button.
 8. Click "Close" button for the guidance.
 9. Click "Close" button on the properties window.
 10. Follow pop-up window to restart computer.
 11. Check if "Standard SATA AHCI controller" or
     "Standard NVM Express controller" driver is installed.
